Why this work matters

Product teams hire designers who can move from problem framing to testable prototypes. Interactive Figma files show how you structure flows, states, and components before engineering commitment.

Process

  • Mapped primary user journeys and edge cases before visual polish.
  • Built reusable components aligned to a simple design system for consistency.
  • Annotated interactions (gestures, transitions, empty states) for developer handoff.

Outcomes & value

  • Shortens alignment cycles between design, PM, and engineering.
  • Demonstrates mobile-first layout and accessibility-minded spacing and type choices.
  • Shows ability to design within real constraints (team library patterns, iteration speed).
