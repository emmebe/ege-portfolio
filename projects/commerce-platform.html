Why this work matters

This visual mockup explores how a commerce site looks across catalog browsing, item detail, cart, and account screens. The emphasis is on visual presentation rather than fully mapping UX navigation or information architecture.

Process

  • Developed visual compositions for browse, detail, cart, and account screens.
  • Explored layout rhythm, screen hierarchy, and component styling.
  • Used representative content to show the visual direction of the site.

Outcomes & value

  • Communicates the site’s visual direction across a multi-screen retail experience.
  • Shows how the brand and interface elements come together on key screens.
  • Provides a visual reference for future UX and navigation work.
