Ways To Slot Machine

Web-based interactive experience translating game-like mechanics into a browser prototype.

Open live site
Game DesignWeb PrototypeInteraction

Why this work matters

Lightweight web prototypes help teams test novelty and feedback loops quickly. Employers see that you can validate a mechanic before committing to a full engine build.

Process

  • Defined player actions, outcomes, and reward feedback for a slot-style loop.
  • Implemented the core interaction in the browser for fast playtesting.
  • Adjusted pacing, copy, and visual feedback based on informal tests.

Outcomes & value

  • De-risks design conversations with something playable in minutes.
  • Connects game design thinking to accessible web tech.
  • Shows bias toward iteration: ship small, learn, refine.
