Museum Collection App

Live web experience for browsing collections with responsive layout and clear navigation.

Open live site
Web DesignFront-endContent Structure

Why this work matters

Shipping a live site shows end-to-end ownership: information architecture, visual design, and implementation. Employers can click through real interactions instead of only static mockups.

Process

  • Structured content types (objects, metadata, filters) before visual design.
  • Built responsive layouts and tested navigation paths on multiple viewport sizes.
  • Iterated on readability, spacing, and component reuse for maintainability.

Outcomes & value

  • Demonstrates ability to deliver a browsable, public-facing product.
  • Highlights collaboration-ready documentation through clear UI patterns.
  • Provides a concrete artifact for walkthroughs in interviews.
