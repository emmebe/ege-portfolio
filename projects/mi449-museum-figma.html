Museum Collection Team Website

Medium-fidelity team website integrating two APIs and a self-built database for museum collection browsing.

Open in Figma
WebMed-FiAPIsData

Why this work matters

Museum browsing UX must make search, filters, and object detail scannable while reflecting real data constraints from APIs and a custom database.

Process

  • Modeled content types and filter patterns around available API fields.
  • Designed list → detail flows with loading, empty, and error states in mind.
  • Coordinated with engineering on what could be dynamic versus static in v1.

Outcomes & value

  • Connects UX deliverables to technical scope (dual APIs + custom DB).
  • Pairs with the live Museum Collection App elsewhere in this portfolio.
  • Shows systems UX: data model thinking, not only marketing pages.
