Menu and UI Design

Menu architecture, visual hierarchy, and interaction patterns for game interfaces.

Open PDF in new tab
UI Design Game UX Visual Hierarchy

Why this work matters

Menu UX is often the first impression of polish. Hiring teams want designers who understand navigation depth, controller/keyboard flows, readability at a glance, and how UI supports the core loop instead of fighting it.

Process

  • Audited player tasks (start, settings, inventory, quit) and prioritized them in the information hierarchy.
  • Explored layout grids, type scales, and iconography for legibility across resolutions.
  • Iterated on affordances and feedback states so players always know what is interactive.

Outcomes & value

  • Shows player-centered interface thinking tied to game goals.
  • Documents visual language decisions teams can extend to HUD and meta screens.
  • Signals production awareness: menus must be implementable and localizable.
