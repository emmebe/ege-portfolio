Why this work matters

Portfolio sites are hiring artifacts themselves. A hi-fi proto shows typography, layout grids, and narrative pacing before code implementation.

Process

  • Structured content sections (intro, work, contact) for recruiter scanning patterns.
  • Applied visual hierarchy and responsive layout assumptions in Figma.
  • Linked pages in prototype mode to test navigation and CTA placement.

Outcomes & value

  • Aligns design intent with the shipped site you maintain elsewhere in this portfolio.
  • Shows web UX skills: spacing, type scale, and component reuse.
  • De-risks development by locking major layout decisions early.
