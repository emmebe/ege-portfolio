Divas and Divs

Interactive web project combining layout craft with playful content presentation.

Open live site
Web DesignCSS LayoutCreative Direction

Why this work matters

Playful sites still need structure: grid systems, type rhythm, and performance-conscious assets. This work shows range beyond utilitarian product UI.

Process

  • Explored visual motifs and layout rhythms that reinforce the project theme.
  • Prototyped responsive breakpoints early to avoid mobile-only retrofits.
  • Balanced animation and imagery with readability and load time.

Outcomes & value

  • Demonstrates visual storytelling and brand tone in a shipped URL.
  • Shows comfort iterating in code, not only in design tools.
  • Useful talking point for teams that value creative front-end collaboration.
